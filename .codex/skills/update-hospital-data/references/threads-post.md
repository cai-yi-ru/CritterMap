# 本月醫院更新的 Threads 文案

資料更新與驗證完成後，由主 agent 整理可直接貼上的文案。使用者指定「先用剛整理好的資料」時，沿用當次證據與已寫入內容；只補影響文章正確性的缺項，不重跑所有院所。維護 skill 本身不啟動醫院查核或自動撰寫當期院所文章。

## 選出真正影響就診的更新

- 「本月」依使用者時區的當次日期，預設 Asia/Taipei。以事件生效期間判斷，不能只依 `Hospital.updatedAt` 或 `HospitalUpdate.updatedAt` 篩選。
- 從本輪已確認、仍適用本月的院所公告與異動選材：休診、加診、時間調整、特寵醫師缺席、預約限制、服務移轉、已營運的新院或新分院。可能早於本月公告、但本月生效的事件也要考慮。
- 選材前逐院對照 `announcements`、`specialClinic`、已確認的欄位異動與 `HospitalUpdates`，不能只從首頁更新動態挑選。工作筆記記下各院「入選／不入選／待確認」及理由，再統計院數；有期限的特約門診須單獨判斷，不因收在一般月班表內就略過。對外以「目前已確認的重點」表述院數；仍有待確認院所或尚未完成清單外補漏時，在工作回報說明範圍。
- 以飼主是否需要改變「去哪間、何時去、找哪位醫師、能看哪些物種」判斷重要性。優先考慮新院或分院、搬遷／停業／服務轉移、收診物種或醫師安排變更、連續多日停診、夜診空窗，以及有期限或名額限制的特別門診；再依迫近程度與影響範圍排序。
- 評論數、查核日期、純潤飾與舊資料校正不包裝成新事件。新收錄不等於新開幕；沒有日期或分院證據的候選不寫成已確認消息。
- 整個縣市更新後，保留所有符合就診影響門檻的更新，每院只摘重點，可合併同院同主題；不固定收錄院數，也不為縮成單篇而刪掉重要程度相當的事件。查核批次的院數與貼文收錄數無關。一般班表、零星半天調整與例行休診通常不入選，除非迫近或對就診有明顯影響。不為湊篇幅或院數加入次要事項。
- 未入選事項留在醫院資料與查核回報，不用串文逐院補齊；使用者另要完整清單時再提供。選材可省略整個次要事件，但入選事件的日期、受影響門診與預約限制須完整，不能靠刪除條件縮短文字。
- 略去已過期細節；必要的背景用已發生語氣。沒有符合條件的重點更新時如實說明，不虛構「本月異動」。

## 整理可直接發布的文字

1. 先完成選材，再依入選事件的已裁決證據整理草稿。保留院名／分院、日期時段、醫師及預約條件；全院休診、特寵門診停診、單一醫師休假及夜診異動必須分清楚。夜診不改寫成急診。
2. 開頭直接點出縣市與月份。每項重點先放已核實的院名，必要時帶分院；院名預設獨立一行，下接精簡的日期、異動與必要預約條件；每院只寫會影響就診安排的內容。用自然的台灣繁中，不把查核工具、欄位數或工作進度放進正文。
3. 以實用資訊、明確受眾與自然互動增加閱讀、分享及回覆的機會。結尾可留一個與物種、地區或就診需求有關的問題；不堆「快收藏、快分享、留言+1」，不捏造親身經歷、療效、恐慌或保證流量。
4. 依入選資訊量安排精簡主文與必要串文，讓每間有重要異動的院所都能被找到；篇幅不足時接續入選院所或補完整日期、時段與條件，不硬刪成固定幾間，也不把次要更新接在後面補成全縣市名單。完成後計算各段字數；若聲稱符合平台上限，先核對當期官方規範。
5. 依 [文字潤飾](writing.md) 讀取並套用 `humanizer-zh-tw`：草稿 → 潤飾 → 對照證據核對語意 → 交付最終稿。自然的原句可保留，刪除公式化開場、宣傳空話與假懸念。院名後直接交代異動，刪去每項前後沒有新增資訊的招呼或提醒；共同提醒集中在文末，個別預約條件仍放在對應院所。不要靠口語贅詞製造親切感。
6. 正文寫明年月與資料核對日，避免「明天」「下週」在轉貼後失去時效。醫院實際就診安排以院方最新公告為準；不因寫貼文刷新資料查核日期。

若提供發文策略或演算法相關說明，使用當期官方來源並附連結，不把相關性寫成流量保證。沒有帳號歷史資料時，依本次內容與受眾編輯，不聲稱已用該帳號數據驗證。

## 交付與收尾

- 交付經 Humanizer 處理的可直接貼上正文；需要串文時依發布順序標示，每段可獨立複製。編輯說明、來源索引與字數放在正文之外。
- 保留各項重點的官方來源供使用者核對或回覆讀者，可附於交付稿末尾；公告連結依 [公告來源連結](field-rules.md#公告來源連結) 優先指向事件原文，補充佐證另列用途與連結，不直接沿用院方首頁或粉專入口。不把來源不足的推測藏在文案中。
- Threads 文案以導流至小獸所主頁地圖為目標：在主文結尾用一句自然的話說明可在地圖找附近的特寵醫院，再附首頁連結 `https://crittermap.snyr.tw/`。縣市文章也預設使用主頁地圖，使用者另指定目的頁時才改用其他連結；正式網域核對 `src/lib/seo.ts` 及實際網頁。串文不重複催促點擊，也不為導流刪掉影響就診的條件。
- 導流句只描述目的頁實際提供的資訊，例如院所名單、電話、地址或看診物種。只有確認本輪異動已部署，才能寫「本月更新已上線／完整異動都在網站」；尚未確認時，使用現有查詢功能作為點擊理由，不把本機更新當成發布完成。
- 本步驟產出草稿，不自動發文、傳訊或回覆他人。新增本月貼文產出為資料更新的收尾項目；僅編修 skill、純潤飾或使用者明確不需貼文時除外。
