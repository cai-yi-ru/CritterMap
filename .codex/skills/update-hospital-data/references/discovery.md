# 查找清單外院所

## 評分與公開裁罰覆核

使用者要求依評分篩選、檢查裁罰，或候選曾被排除時，將收錄判斷與當期特寵服務查核分開記錄。

- 沿用使用者明確指定的門檻，保存分數、評論數及實際 Maps 查核日。未指定時提出建議，不自行把 3.7～3.9 分全數排除或核准。新增、恢復及既有條目均須盤點；政策未定時不批次刪除既有院所。
- 先核對院名、舊名、分院、地址、電話及可取得的負責獸醫或開業證號。改名或搬遷的主體延續沒有證據時，保留身分缺口。
- 查地方動保／農業機關的具名公告、獸醫師或診療機構處分、官方訴願／裁判資料，另查 [勞動部公告](https://announcement.mol.gov.tw/) 和 [環境部裁處查詢](https://prtr.moenv.gov.tw/deal.html)。能操作時實際提交公開查詢表單，記錄院名、日期範圍及結果；遇驗證碼不自行解碼或繞過。
- 優先讀官方逐筆資料。官方新聞稿可以支持機關曾宣布開罰，不能補造案號、裁處日、法條或撤照結果。第三方即使標示來自官方 API，也須核對官方個案；原件讀不到就標為待核線索。
- 逐筆記錄違規日、裁處日、公告日、機關、案號、原因、金額、身分匹配及可查得的撤銷／救濟／改善狀態；未列欄位保持未知。繳清罰鍰不等於所有問題已改善。
- 區分獸醫執業、動物福利、勞動職安與環保案件。裁判中醫療費收據、名冊、補助款、新聞轉載及其他分院紀錄不能當成本院裁罰；匿名案件不能猜院名。
- 沒找到只能寫「本輪未查到可確認歸屬的公開紀錄」，列查核日期、範圍、受阻及未完成查詢；不得寫成「無裁罰」「安全」或「已排除所有問題」。

將結果及來源存於 `docs/hospital-penalty-audit-YYYY-MM-DD.md`；必要時在縣市稿的覆核筆記附重點及官方連結，筆記不屬於 Threads 正文。這次查詢不刷新全院 `last_checked`、醫療來源日期或評分日期。

涉及無資格診療、動物福利或有效停業／執照處分時，優先提出暫不收錄與待確認項目；勞動、環保案件依事由、時間、後續狀態及使用者政策個別判斷。區分建議與已採用政策；修改有效清單後，同步處理動態、Threads 選材及歷史紀錄，沿用原 ID。

縣市名單更新時必讀；使用者明確限定既有院所、抽樣或單欄位時，不擴大範圍。這一步包含新開幕院所、原本漏收的既有院所，以及既有犬貓院所新設的特寵門診，不限最近開幕者。

## 1. 建立收錄基準

- 讀 `src/lib/getHospitals.ts`，以實際匯入的有效物件建立全站院所索引；不要只比對目標縣市檔案。
- 記錄院名、舊名／別名、分院、地址、電話、官方入口及可確認的 Google 識別。註解內的歷史條目不算有效收錄，但可作改名、搬遷或停業的查核線索。
- 曾被註解或移除的院所，先用 `git log`、`git blame` 與當次 diff 查明排除原因。官方仍提供特寵診療不代表原排除原因已解除；原因未查明或尚未解除時，維持原排除狀態並記錄待確認事項。只有新證據支持解除原原因，或使用者明確變更收錄政策時，才恢復既有 ID，並寫「恢復收錄」，不當成首次新增。文案來源查核不能替代這項收錄判斷。
- 維護既有目標清單與清單外候選清單；發現可查核的新候選時更新待處理數，不把每批上限當成總數。

## 2. 搜尋候選

從公開網路搜尋與 Google Maps 查找目標縣市的特寵院所，不能只沿用既有醫院 URL。搜尋須涵蓋「特寵／異寵醫院」及不同物種門診；例如「高雄 兔鼠 動物醫院」、「高雄 鳥類 獸醫」、「高雄 爬蟲 動物醫院」，再依具體缺口加入行政區、開幕、新院或特寵部門等條件。

第三方名單、飼主推薦與搜尋摘要只作線索。每個有可能未收錄的院所都要讀院方官網、正式公告、官方社群或預約頁，核對：
- 是否位於目標縣市、屬於哪個分院，以及目前是否已營運。
- 是否明示在該院提供非犬貓診療；照片、病例、醫師履歷、送驗或一般寵物業務不足以確認。
- 官方名稱、地址、聯絡方式與當期就診限制。成立、開幕、搬遷、查核及發布日期分開記錄。

同一路徑失敗依主文件的停止條件換官方入口。沒有可用替代證據就記缺項，不為取得候選數而降低證據標準。

## 3. 去重與分類

每個候選和全站有效清單交叉比對，不只用院名判斷：

| 判定 | 處理 |
| --- | --- |
| 同院改名、搬遷、名稱格式差異 | 更新既有條目，沿用 id；不新增重複院所 |
| 已收錄犬貓院所新增特寵門診 | 核實該分院的物種與門診限制，更新既有服務／分類 |
| 新分院或特寵部門獨立設院 | 依官方公告確認獨立身分；符合收錄條件才新增 |
| 未收錄且已營運，明示特寵診療 | 排入完整條目查核；必要欄位可靠後新增 |
| 尚未營運、已停業、非醫療院所或證據不足 | 不加入有效清單；回報原因及待確認資料 |

新增按 [欄位判定](field-rules.md) 核對身分、必要欄位與精確座標，按 [多院委派](multi-hospital.md) 排入後續批次。缺少選填的預約、急診或週表資料時留未填；不以 `false`、空陣列或猜測值湊出完整條目。若必要欄位或當期特寵診療無可靠證據，維持候選，不寫入半成品。

主 agent 親自覆核新增院所的身分、位置及特寵受理證據，再依主文件潤飾、改檔與驗證。新條目須進入實際彙整入口，新增 id 不得與全站有效條目重複。首次收錄可建立 `content` 動態，寫「新增收錄」；只有開幕日期獲官方支持時才寫「新開幕」。

## 4. 回報與完成條件

回報搜尋的縣市、關鍵字／來源範圍與查核日，逐一列候選名稱、判定、對應既有 id 或新增 id、主要官方來源，以及未新增的原因／缺項。統計候選、已收錄／同院、實際新增、待確認及排除數，候選判定不得漏項。

縣市更新完成須同時涵蓋既有條目查核及清單外搜尋；候選已處理或明確保留待確認後才收尾。沒找到可新增者應寫「本輪搜尋未找到可確認新增的院所」，不宣稱全市沒有新院或已全部收錄。搜尋未執行、受阻或只查了部分來源時明說，不將既有條目全部處理冒充為已完成補漏。
