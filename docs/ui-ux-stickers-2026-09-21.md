# 首頁搜尋與動物貼圖調整

## 介面

- 縣市、常見物種、更多物種、其他條件與搜尋按鈕依操作順序排列；進階條件預設收合，已選數量保留於標題。
- 手機首屏縮短介紹，物種按鈕使用同一套尺寸與選取狀態。
- 手機搜尋成功後移到結果摘要，並尊重減少動態效果設定。
- 手機醫院清單使用頁面捲動，每次增加 10 間，焦點移到第一張新增卡片；桌面保留 640px 清單與地圖並排。
- 醫院摘要保留完整且去重的物種分類，卡片優先顯示查詢物種，再顯示其他特寵；超過三類顯示剩餘數量。
- 修正「守宮（蜥蜴）」正式名稱的分類對應與網址回填。

## 圖示

- 使用內建 image_gen 生成 19 張獨立透明 PNG，以兔子作為其餘圖示的風格參考。
- 原始圖：`assets/pet-stickers/`；正式 WebP：`public/pet-icons-v3/`。
- `scripts/processPetStickers.cjs` 將原圖縮放、保留透明度並加安全留白，輸出 192 × 192 WebP。
- 已驗證 19 張圖皆有透明與不透明像素，正式素材合計 237,014 bytes。
- 所有使用 `PetIcon` 的篩選、卡片與詳情同步採用新版圖示；已有文字標籤時不重複朗讀圖片名稱。
- 原始提示詞：`pet-stickers-v3-prompts.json`；大小對照：`pet-stickers-v3-preview.html`。

## 驗證

- ESLint、TypeScript 與隔離目錄內的 Next.js 正式建置通過。
- `node scripts/validateSite.mjs http://127.0.0.1:3101`：53 項檢查通過，包含倉鼠卡片與守宮網址回填回歸檢查。
- Chrome 實測 CSS viewport 320、768、1440px 無水平溢出；320px 清單沒有內層垂直捲軸，1440px 清單為 640px 高。
- 實測倉鼠優先顯示、更多物種／守宮選取、載入 10 → 20 間與第 11 張卡片焦點、急診條件、地圖切換、醫院詳情、零結果與清除條件。
- 圖示總覽的 76 個圖片實例（19 款 × 4 種展示尺寸）全部載入；桌面八個物種按鈕實測高度一致。

以上為部署前的本機修改與驗證紀錄；後續發布狀態以 GitHub main 的 Vercel Production 部署紀錄為準。
