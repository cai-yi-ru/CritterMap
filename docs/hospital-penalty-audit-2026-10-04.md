## 查核方法與限制

- 主 agent 以 Chrome 實際操作[勞動部公告](https://announcement.mol.gov.tw/)，未設縣市、法規或日期限制，查院名與可辨識簡稱；逐項讀五類結果。頁面「最近三年總筆數」是統計說明，表格仍顯示部分更早紀錄，例如全國台北分院 2015 年案件；不能將空白日期搜尋說成完整歷年檔案。
- 主 agent 操作[環境部裁處系統](https://prtr.moenv.gov.tw/deal.html)，以「動物醫院」查 2021/10/4～2026/10/3，共五筆，逐筆名單僅大直屬本次目標；大直詳細內容核對院址。另查 2007/1/1～2011/12/31，未取得台大候選原始列。沒有查完所有年份、曾用名或法人名稱。
- GPT-6 Luna／max workers 查台北、基隆、新竹、苗栗及台中目標的官方動保、獸醫執業、訴願／司法、環保公開資料，核對院名與登記身分。嘉義兩院、高雄宏力及屏東福爾摩莎由主 agent 查精確名稱、地點與政府公開索引，再查上述勞動／環保表單。
- 未公開、匿名、未索引、待審案件及不同登記主體都可能形成缺口；部分名冊原件或裁處全文無法讀取。勞動訴願表單需要驗證碼，未解碼或繞過。報告不是診療執照現況或醫療品質認證。
