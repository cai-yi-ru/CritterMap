# Threads 文案覆核頁

路徑：`/review/threads`。本機執行 `npm run dev` 後即可開啟；正式網站需部署此次變更後才有此頁。

頁面直接讀取本目錄的 `YYYY-MM-縣市-threads.md`，不另外維護一份文案資料。新增或修改草稿後，本機 dev 會在重新整理時讀取；正式版需要重新 build／部署。

- **文案**：保留 `text` 程式碼區塊中的主文與留言原文，可逐則複製。
- **來源備查**：列出來源網址及用途，新分頁開啟。支援「來源備查」、「來源與查核範圍」及台南原稿的「查核與選材回報」。筆數是連結數，不是入選醫院數。
- **查核結果**：顯示獨立文案查核、選材、資料查核限制及原來源備查說明。「獨立文案覆核通過」只依獨立文案查核段落的判定，不以 TypeScript 或醫院資料驗證通過代替。
- **我已覆核**：只保存在這個瀏覽器，不會回寫文件，也不會改動獨立 reviewer 的狀態。草稿內容變更後使用新的紀錄版本。

本頁沒有公開導覽入口，不列入 sitemap；頁面 metadata 及 `/review/*` 的 `X-Robots-Tag` 均設為 `noindex`。robots.txt 保留允許爬取，讓搜尋引擎能讀到排除索引指令。這不是登入保護，知道網址的人仍可存取。

可用 `npm run check:site -- http://localhost:3030` 檢查正式版的 noindex、HTTP header、sitemap 排除，以及公開頁面的索引設定未受影響。
